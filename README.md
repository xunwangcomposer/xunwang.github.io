# Xun Wang Composer Website Framework

## Features
- Glassmorphism Home
- Biography
- Works (modal ready)
- CV PDF viewer
- Gallery
- Contact
- Responsive
- Parallax scaffold
- GitHub Pages ready

## Deploy
1. Create a GitHub repository named USERNAME.github.io
2. Upload all files.
3. Go to Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main /(root).
6. Wait 1 minute.
